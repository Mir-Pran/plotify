# Plotify Bangladesh 🇧🇩

Plotify is a modern, feature-rich real estate marketplace web application built specifically for Bangladesh (inspired by modern real estate platforms)[cite: 8]. It provides a seamless platform to find, buy, sell, and rent verified apartments, houses, plots, mess rooms, and hotels across Bangladesh with direct owner contact[cite: 8].

---

## 🚀 Key Features

* **Wide Range of Properties**: Browse apartments, independent houses, plots, mess rooms, and hotel rooms[cite: 8].
* **Verified Listings**: Direct property listings with verified owner information to ensure safe transactions[cite: 8].
* **Advanced Search & Filters**: Search locations across major cities and hubs in Bangladesh (e.g., Dhaka, Gulshan, Bashundhara, etc.)[cite: 8].
* **Direct Owner Contact**: Connect instantly with property owners or agents without middlemen.
* **Interactive UI/UX**: Clean, responsive, and modern interface built with Next.js, Tailwind CSS, and Lucide Icons[cite: 8].
* **Secure Authentication**: Robust user authentication and profile management systems[cite: 8].

---

## 🛠️ Tech Stack

* **Framework**: [Next.js](https://nextjs.org/) (App Router)[cite: 8]
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)[cite: 8]
* **Database & Backend**: [Supabase](https://supabase.com/)[cite: 8]
* **Icons**: Lucide React[cite: 8]
* **Deployment**: Vercel
